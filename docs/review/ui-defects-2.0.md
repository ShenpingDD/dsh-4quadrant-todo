| 视口 | 页签 | 节点数量 | 溢出节点 | 结论 |

| 1920×1080 | 四象限 | 4 方格、1 卡片 | 无 | 正常 |

## 3. 布局目标

| 选择器 | 规则 |
| --- | --- |
| `.tc-shell` | 宽度 100%，取消 max-width，取消居中边距，内边距 `0 clamp(12px,1.2vw,24px) clamp(8px,1vh,16px)` |
| `.tc-grid` | 两列两行，`repeat(2,minmax(0,1fr))`，间距 `clamp(8px,0.9vw,16px)` |
| `.tc-stat-grid` | `repeat(auto-fit,minmax(220px,1fr))` |
| `.tc-list-head` | 弹性单行，`min-height:32px`，内边距 `6px 8px`，不继承行网格 |
| `.tc-list-row` | 网格四列：标题自适应、截止 120px、完成 150px、操作自适应，行高不小于 36px |
| `.tc-tabpanel` | 页签内容外层，铺满可用高度，承载切换动画 |

断点分两类：卡片密度按视口宽度，栅格布局按面板内容宽度（`.tc-page` 声明 `container-type:inline-size`）。

| 视口宽度 | 行为 |
| --- | --- |
| 1720 及以上 | 象限体与今日页分区内卡片两列，间距交给 gap |
| 1181 至 1719 | 四象限两行两列，卡片单列 |
| 1180 及以下 | 间距 8px，卡片内边距 4px 6px，象限名 12px |

| 面板内容宽度 | 行为 |
| --- | --- |
| 大于 640px | 四象限两行两列 |
| 640px 及以下 | 四象限改纵向弹性列，整页滚动承载在 `.tc-shell`，每格最小高度 40vh |

## 4. 四象限配色目标

`--tc-quadrant` 令牌保持不变，四个 `data-tc-quadrant` 选择器各自写死比例。

| 象限 | 令牌 | 头部混色 | 左缘宽度与混色 | 等级文案 |
| --- | --- | --- | --- | --- |
| urgent-important | `--dsw-alias-state-error-primary` | 22% | 4px，68% | 立刻处理 |
| urgent-not-important | `--dsw-alias-state-warn-primary` | 18% | 4px，60% | 尽快处理 |
| not-urgent-important | `--dsw-alias-state-business-primary` | 14% | 4px，52% | 排入计划 |
| not-urgent-not-important | `--dsw-alias-state-idle-primary` | 8% | 4px，36% | 有空再做 |

卡片左缘 3 像素，颜色取所在象限 56% 混 `label-primary`（该混色对卡片面的对比度在浅色为 4.06 至 9.57，深色为 5.19 至 8.82，见 `docs/review/quadrant-palette.md`）；标题前加 6 像素象限圆点，颜色与卡片左缘同源；逾期卡片加 1 像素红色描边、时间文字红色、逾期天数徽标。

## 5. 动效目标

变量：`--tc-dur-fast` 120ms，`--tc-dur-base` 180ms，`--tc-ease` 为 `cubic-bezier(.2,.7,.3,1)`，定义在 `.tc-page`。

| 场景 | 规则 |
| --- | --- |
| 卡片进入 | `tc-rise` 180ms，位移 4 像素加透明度，只在新挂载节点播放 |
| 卡片悬停 | 边框、阴影、位移 120ms，悬停上移 1 像素 |
| 按钮按下 | 缩放 .94，120ms |
| 页签切换 | 内容容器 140ms 淡入，容器带 tab 键值 |
| 折叠箭头 | 旋转 180ms |
| 拖拽落点 | 边框呼吸 1.2s 循环 |
| 减少动态效果 | `prefers-reduced-motion: reduce` 下动画与过渡时长归零 |

## 8. 交互复核补记

本轮截图复核时补齐的交互，均已写进 `lib/client.js` 并有套件覆盖：

1. 勾选完成带未完成子待办的待办时弹出合并确认框，确认后父与子一并完成。
2. 完成动作写入后页面时钟随数据刷新，已完成页立刻列出刚完成的条目，统计页同区间计数同步变化。
3. 新建面板的子待办为逐行输入：默认 0 行，点「添加一行」插入一行并聚焦，行尾「移除」，按钮随行数改为「再添加一行」；点击面板外部关闭面板。
4. 快速录入的时段词（上午、中午、下午、傍晚、晚上）参与截止时刻推导，预览区的日期与时刻就是提交值。
5. 筛选区的标签浮层与预设面板由页面级状态托管，Esc 依次关闭对话框、卡片菜单、浮层、确认框、编辑面板、多选与面板本身。
6. 保存预设只写数据，套用发生在点击预设条目时。
7. 导入确认对话框展示文件原值：版本号、待办条数、筛选条数。
8. 重复行的间隔与终止日期带完整说明，规则预览为「每 N 周重复，到 <日期> 结束」。
9. 计划截止时间在本机时间与 ISO 8601 之间只补一次秒位：`toIso` 接受 `YYYY-MM-DDTHH:mm` 与 `YYYY-MM-DDTHH:mm:ss`，秒位缺省补 `00`，再按本机时区拼上偏移；年月日时分秒回读不一致时抛出「截止时间格式不正确」，提示显示在编辑面板的错误行。
10. 主色按钮悬停保持主色底并加深一档（`color-mix(in srgb, var(--dsw-alias-brand-primary) 88%, #000)`），边框同色，上移 1 像素，文字保持 `--dsw-alias-bg-base`；实测悬停态前景 `rgb(255, 255, 255)`、背景约 `rgb(13, 15, 18)`、对比度 19.19。

最终套件结果：`verify-api-v2` 34 项、`verify-host-rules` 39 条、`audit-static` 9 项、`check-client-load` 7 项、`ui-check` 17 项、`ui-check-v11` 43 项、`ui-check-v2` 61 项（其中 4 项只读升级分支在版本 2 数据下按设计跳过）、`ui-layout` 18 项、`ui-check-edit` 18 项，全部零失败。

## 9. 断点与配色口径

栅格布局按面板内容宽度判定（`.tc-page` 声明 `container-type:inline-size`）：内容宽度大于 640px 时四象限两行两列，640px 及以下改纵向单列，整页滚动承载在 `.tc-shell`。卡片密度按视口宽度三档（1720 及以上、1181 至 1719、1180 及以下）。取值见 `docs/ui-spec-v2.md` 2.2 与 `docs/review/quadrant-palette.md`。
