# 四象限配色档

本文件记录四象限染色用到的令牌、混色比例、浅色与深色两套主题下的最终色值，以及 WCAG 对比度算式与结果。规则来源为 `docs/ui-defects-2.0.md` 第 4 节，界面规则写在 `docs/ui-spec-v2.md` 第 1.4 节。

## 2 算式

混色按 sRGB 伽马编码分量直接插值，与浏览器 `color-mix(in srgb, …)` 一致：

```text
C = p × A + (1 − p) × B        每个通道分别计算，结果四舍五入到 0 至 255
```

对比度按 WCAG 2.1 相对亮度计算，分量先线性化：

```text
c  = 通道值 ÷ 255
c' = c ÷ 12.92                       当 c ≤ 0.03928
c' = ((c + 0.055) ÷ 1.055) ^ 2.4     当 c > 0.03928
L  = 0.2126 × R' + 0.7152 × G' + 0.0722 × B'
对比度 = (L亮 + 0.05) ÷ (L暗 + 0.05)
```

以「紧急且重要」头部浅色为例，22% `#ec1313` 混入 `#ffffff`：

```text
R = 0.22 × 236 + 0.78 × 255 = 250.82 → 251 → fb
G = 0.22 × 19  + 0.78 × 255 = 203.08 → 203 → cb
B = 0.22 × 19  + 0.78 × 255 = 203.08 → 203 → cb
头部底色 = #fbcbcb
```

`label-primary` 与该头部底色的对比度：

```text
L(#fbcbcb) = 0.2126 × 0.9648 + 0.7152 × 0.5972 + 0.0722 × 0.5972 = 0.6753
L(#0f1115) = 0.2126 × 0.00518 + 0.7152 × 0.00605 + 0.0722 × 0.00787 = 0.0056
对比度 = (0.6753 + 0.05) ÷ (0.0056 + 0.05) = 0.7253 ÷ 0.0556 = 13.05
```

## 5 判定

文字门槛 4.5:1，图形元素与边框门槛 3:1。

| 项 | 浅色 | 深色 | 判定 |
| --- | --- | --- | --- |
| 头部文字 `label-primary` 对头部底色 | 13.05 至 18.42 | 10.64 至 14.28 | 通过 |
| 方格左缘 4 像素对头部底色 | 4.30 至 7.72 | 5.03 至 8.10 | 通过 |
| 卡片左缘 3 像素对卡片面 | 1.24 至 2.64 | 1.41 至 3.05 | 未通过（深色仅 紧急不重要 达到 3.05） |

头部四个底色分别为浅色 `#fbcbcb`、`#fdeed3`、`#e4ecfc`、`#fcfcfc`，深色 `#512f30`、`#493920`、`#2f3643`、`#272728`，四个方格互不相同。

## 6 调整建议

卡片左缘在 `bg-layer-1` 基下达不到 3:1。把混入基准换为 `label-primary`，比例仍取 56%，四个象限全部达到 3:1，且与方格左缘同一色相：

| 象限 | 现状对卡片面（浅 / 深） | 建议色值 浅 | 浅色比值 | 建议色值 深 | 深色比值 |
| --- | --- | --- | --- | --- | --- |
| 紧急且重要 | 2.64 / 2.23 | `#8b1214` | 9.57 | `#f5a0a1` | 6.92 |
| 紧急不重要 | 1.54 / 3.05 | `#90600f` | 5.43 | `#f7c675` | 8.82 |
| 重要不紧急 | 2.12 / 2.92 | `#2b4a8a` | 8.57 | `#b2cdfd` | 8.66 |
| 不重要不紧急 | 1.24 / 1.41 | `#7d7e80` | 4.06 | `#9d9e9f` | 5.19 |

保留 `bg-layer-1` 基准时，提高比例只在两个象限内可行：

| 象限 | 达到 3:1 所需的混色比例 | 对应色值 | 对卡片面 |
| --- | --- | --- | --- |
| 紧急且重要 | 64% | `#f36868` | 3.00 |
| 重要不紧急 | 79% | `#6993eb` | 3.01 |
| 紧急不重要 | 100% 时为 2.15 | `#f59e0b` | 2.15 |
| 不重要不紧急 | 100% 时为 1.48 | `#d4d4d4` | 1.48 |

紧急不重要与不重要不紧急这两个象限在白色基准下无论比例多高都到不了 3:1，卡片左缘必须取 `label-primary` 作混入基准。

## 7 使用约束

卡片圆点、方格左缘与卡片左缘取同一象限的派生色，比例各自固定，不随状态变化。

头部文字只用 `label-primary`：名称 13.5/20 500、等级文案 12/18 400、计数 12/18 400。`label-secondary` 在「紧急且重要」头部浅色底上为 4.01，低于正文 4.5:1，头部不使用该令牌。

纯状态色不作图形：警告色对白色 2.15、空闲灰对白色 1.48、空闲灰对深色卡片面 1.87，都低于 3:1。

逾期的红色只用于两处图形：1 像素描边对卡片面为 4.50（浅）/ 4.24（深），「逾期 N 天」徽标底为 6% 状态错误混入 `bg-layer-2`，徽标文字取 `label-primary`，对比度 17.16（浅）/ 12.41（深）。时间文字取 `label-primary`，深色下错误色对卡片面为 4.24，低于正文 4.5:1。
